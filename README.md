# JAVA---POO

## Retos Extra: Programación Orientada a Objetos (POO)

### Instrucciones

Completa los retos extra del ejercicio de Programación Orientada a Objetos (POO).

### Tareas a Implementar

#### 1. Calcular la Nota Promedio

Implementa una función que calcule la nota promedio para ese curso.

#### 2. Ranking de Estudiantes

Implementa una función que muestre un ranking con todos los estudiantes matriculados en el curso y sus respectivas notas.

#### 3. Comparación con la Media

Implementa una función que, para cada estudiante, indique si está por encima del promedio del curso o no.
